HTTP

HyperText Transfer Protocol — websites ka data transfer hota hai. GET, POST requests yahan dikhti hain. Unencrypted hoti hain — sensitive data clearly visible hota hai.

DNS

Domain Name System — jab browser kisi website ka naam resolve karta hai IP mein. DNS queries unencrypted hoti hain — koi bhi dekh sakta hai tum kahan ja rahe ho.

TLS/HTTPS

Encrypted traffic — HTTPS websites ka data TLS se protect hota hai. Wireshark mein dikhta hai lekin decrypt nahi hota bina private key ke.

ARP

Address Resolution Protocol — IP address se MAC address dhundta hai local network mein. ARP Spoofing attack isi protocol ko target karta hai.

TCP

Transmission Control Protocol — reliable data delivery ensure karta hai. SYN, SYN-ACK, ACK — teen-way handshake se connection establish hota hai.

ICMP

Internet Control Message Protocol — ping command isi se kaam karta hai. Network troubleshooting ke liye use hota hai. ICMP flood se DDoS attack bhi hota hai.
